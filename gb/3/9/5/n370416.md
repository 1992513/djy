<tr><td VALIGN=TOP width="626"><h2 align=center>食物需巧搭配</h2>
<h6></h6>
<hr>【大纪元9月5日讯】在餐桌上，一种食物与另一种或几种食物巧妙地搭配，可能起到取长补短、兴利除弊、营养互补、相辅相成的作用，相反，有些食物如果搭配错，则营养价值就会降低，甚至会引起不良反应而致病，也就是人们传统上说的食物“相克”。<br/>　　<br/>　　宜搭配的食物<br/>　　<br/>　　芝麻配海带 芝麻与海带同食，能美容、抗衰老。因为芝麻能改善血液循环，促进新陈代谢，芝麻中的亚油酸有调节胆固醇的功能，维生素E又可防衰老。海带含有丰富的钙和碘，能净化血液，促进甲状腺素的合成，两者同食，效果倍增。<br/>　　<br/>　　牛肉配土豆 牛肉营养价值高，并有健脾胃的作用。但牛肉粗糙，有时会损伤胃粘膜，土豆与之同煮，不但味道好，且土豆含有丰富的维生素，能起到保护胃粘膜的作用。<br/>　　<br/>　　百合配鸡蛋 中医认为，百合清痰火，补虚损，而蛋黄能除烦热，补阴血，两者同食，有滋阴润燥、清心安神的功效。<br/>　　<br/>　　羊肉配生姜 羊肉补阴生暖，生姜驱寒保暖，相互搭配，暖上加暖，同时还可驱外邪，治寒胃痛。<br/>　　　<br/>　　豆腐配鱼类 豆腐煮鱼，不仅味道鲜美，而且可预防骨质疏松、小儿佝偻病等缺钙引起的疾病。因为豆腐中含有大量的钙元素，若只吃豆腐，机体对钙的吸收率会很低，但与富含维生素D的鱼类一起吃，就可大大增加机体对钙的吸收和利用。<br/>　　<br/>　　菠菜配胡萝卜 每天吃一定量的菠菜和胡萝卜，可明显降低中风危险，这主要是得益于二者中高含量的胡萝卜素，它可以转化成维生素A，防止胆固醇在血管壁上沉积，保持脑血管通畅而防止中风。<br/>　　<br/>　　红葡萄酒配花生米 法国有一个奇怪的现象，尽管人们习惯吃的饭菜中脂肪和胆固醇含量很高，但心脏病的发病率却很低，这种现象得益于法国人餐桌上饮食搭配———红葡萄酒加花生米。红葡萄酒中含有阿司匹林的成分，花生米中含有益的化合物白梨醇，二者能预防血栓形成，保证心血管通畅，能大大降低心脏病的发病率。<br/>　　<br/>　　忌搭配的食物<br/>　　<br/>　　豆浆＋鸡蛋 鸡蛋中的粘生蛋白能与豆浆中的胰蛋白脢结合，从而失去应有的营养价值。<br/>　　<br/>　　米汤＋奶粉 奶粉中含有维生素A，而米汤则以淀粉为主，含有脂肪氧化脢，能破坏奶粉中的维生素A。长期用米汤冲奶粉喂孩子，会使孩子生长发育迟缓，抗病能力减弱。<br/>　　<br/>　　开水＋蜂蜜 蜂蜜中的脢类物质遇热水后，会释放出过量的羟甲基糖酸，使蜂蜜中的有效营养成分被迅速破坏。<br/>　　<br/>　　小葱＋豆腐 豆腐含钙较多，与小葱相拌时，会与小葱中的草酸结合成草酸钙，人体难以吸收。<br/>　　<br/>　　海味＋水果 鱼虾、藻类含有丰富的蛋白质和钙等营养物质，如果与含鞣酸的水果同食，不仅会降低蛋白质的营养价值，而且易使海味中的钙质与鞣酸结合，形成一种不易消化的物质。这种物质可刺激粘膜，使人出现腹痛、恶心、呕吐等症状。<br/>　　<br/>　　啤酒＋海味 饮啤酒时用海味佐菜下酒，易引发痛风症。这是因为痛风本身有无法排泄的过多尿酸，而海味又会刺激人体制造更多的尿酸，导致雪上加霜，使病情加重。<br/>　　<br/>　　肉类＋茶饮 茶中的大量鞣酸与蛋白质结合，会生成具有收敛性的鞣酸蛋白质，使肠蠕动减慢，延长粪便在肠道内的潴留时间，易形成便秘。<br/>　　<br/>　　咸鱼＋西红柿 咸鱼不易与西红柿（香蕉及乳酸饮料）搭配食用。由于咸鱼制品中的硝酸盐在乳酸杆菌的作用下还原成亚硝酸盐，再加上西红柿等所含有的胺类，易引起胃、肠、肝等消化器官发生癌变。<br/>　　<br/>　　虾＋维生素食物C 由于环境污染的缘故，虾大多含有五种价砷化物，它们本身对人体健康无害，但若与含维生素C的食物同食，在化学作用下，虾体内的五价砷可转化成剧毒的三价砷，造成人体中毒。@</p><font
