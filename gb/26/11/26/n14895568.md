<tr><td VALIGN=TOP width="626"><h2 align=center>西澳91个医院病区实施护患新配比</h2>
<h6></h6>
<hr>
<p>【大纪元2026年11月26日讯】（大纪元记者林达澳洲珀斯报导）西澳政府已将护士与患者最低人数配置比例（护患配比）扩大至<span lang="en-AU">91</span>个都市地区医院病区及所有都市地区急诊科。</p>
<p><span lang="zh-TW">西澳卫生厅长哈马特（</span><span lang="en-US"><span lang="en-AU">Meredith</span> <span lang="en-AU">Hammat</span></span><span lang="zh-TW">）</span><span lang="en-US"><span lang="en-AU">11</span></span><span lang="zh-TW">月</span><span lang="en-US"><span lang="en-AU">16</span></span><span lang="zh-TW">日宣布，最后</span><span lang="en-US"><span lang="en-AU">33</span></span><span lang="zh-TW">个病区已开始实施相关标准。此次扩展涉及</span><span lang="en-US"><span lang="en-AU">12</span></span><span lang="zh-TW">家都市地区医院及医疗服务机构，包括阿马代尔医疗服务中心（</span><span lang="en-US"><span lang="en-AU">Armadale</span> <span lang="en-AU">Health</span> <span lang="en-AU">Service</span></span><span lang="zh-TW">）、本特利医院（</span><span lang="en-US"><span lang="en-AU">Bentley</span> <span lang="en-AU">Hospital</span></span><span lang="zh-TW">）、菲奥娜</span><span lang="en-US"><span lang="en-AU">·</span></span><span lang="zh-TW">斯坦利医院—科伯恩医疗中心（</span><span lang="en-US"><span lang="en-AU">Fiona</span> <span lang="en-AU">Stanley</span> <span lang="en-AU">Hospital–Cockburn</span> <span lang="en-AU">Health</span></span><span lang="zh-TW">）、弗里曼特尔医院（</span><span lang="en-US"><span lang="en-AU">Fremantle</span> <span lang="en-AU">Hospital</span></span><span lang="zh-TW">）、爱德华国王纪念医院（</span><span lang="en-US"><span lang="en-AU">King</span> <span lang="en-AU">Edward</span> <span lang="en-AU">Memorial</span> <span lang="en-AU">Hospital</span></span><span lang="zh-TW">）、默里地区医院（</span><span lang="en-US"><span lang="en-AU">MurrayDistrictHospital</span></span><span lang="zh-TW">）、奥斯本公园医院（</span><span lang="en-US"><span lang="en-AU">Osborne</span> <span lang="en-AU">Park</span> <span lang="en-AU">Hospital</span></span><span lang="zh-TW">）、皮尔医疗中心（</span><span lang="en-US"><span lang="en-AU">Peel</span> <span lang="en-AU">Health</span> <span lang="en-AU">Campus</span></span><span lang="zh-TW">）、珀斯儿童医院、查尔斯</span><span lang="en-US"><span lang="en-AU">·</span></span><span lang="zh-TW">盖尔德纳爵士医院（</span><span lang="en-US"><span lang="en-AU">Sir</span> <span lang="en-AU">Charles</span> <span lang="en-AU">Gairdner</span> <span lang="en-AU">Hospital</span></span><span lang="zh-TW">）、罗金厄姆综合医院（</span><span lang="en-US"><span lang="en-AU">Rockingham</span> <span lang="en-AU">General</span> <span lang="en-AU">Hospital</span></span><span lang="zh-TW">）及皇家珀斯医院（</span><span lang="en-US"><span lang="en-AU">Royal</span> <span lang="en-AU">Perth</span> <span lang="en-AU">Hospital</span></span><span lang="zh-TW">）。</span></p>
<p>护患配比制度根据病区患者人数设定最低护士配置标准。此前已在部分普通内科及外科病区实施的标准为：早班和下午班每<span lang="en-AU">4</span>名患者至少配备<span lang="en-AU">1</span>名护士，另设<span lang="en-AU">1</span>名不负责直接护理的当班协调员；夜班则每<span lang="en-AU">7</span>名患者至少配备<span lang="en-AU">1</span>名护士。具体配置会因临床环境、患者需求及班次而异，并非所有病区及急诊科均采用相同比例。</p>
<p><span lang="zh-TW">这项改革于</span><span lang="en-US"><span lang="en-AU">2023</span></span><span lang="zh-TW">年</span><span lang="en-US"><span lang="en-AU">7</span></span><span lang="zh-TW">月在珀斯儿童医院急诊科试行，之后分阶段扩展至其他医院病区，</span><span lang="en-US"><span lang="en-AU">2026</span></span><span lang="zh-TW">年</span><span lang="en-US"><span lang="en-AU">2</span></span><span lang="zh-TW">月进一步涵盖重症监护、冠心病监护、新生儿及儿科护理相关科室。</span></p>
<p><span lang="zh-TW">新制度将逐步取代“每名患者每日护理时数”（</span><span lang="en-US"><span lang="en-AU">Nursing</span> <span lang="en-AU">Hours</span> <span lang="en-AU">per</span> <span lang="en-AU">Patient</span> <span lang="en-AU">Day</span></span><span lang="zh-TW">，简称</span><span lang="en-US"><span lang="en-AU">NHpPD</span></span><span lang="zh-TW">）人员配置模式。西澳卫生厅表示，在尚未实施新配比的病区，</span><span lang="en-US"><span lang="en-AU">NHpPD</span></span><span lang="zh-TW">仍将作为主要工作量管理方式，直至完成制度转换。</span></p>
<p>哈马特表示，合理的工作负担是提供高质量患者护理服务的重要前提，新制度是对护士和助产士所反映问题的回应。</p>
<p><span lang="zh-TW">不过，改革此前因延迟实施受到澳大利亚护理与助产士联合会西澳分会（</span><span lang="en-US"><span lang="en-AU">ANMFWA</span></span><span lang="zh-TW">）批评。《澳大利亚护理与助产士杂志》</span><span lang="en-US"><span lang="en-AU">9</span></span><span lang="zh-TW">月</span><span lang="en-US"><span lang="en-AU">14</span></span><span lang="zh-TW">日报导，珀斯地区超过</span><span lang="en-US"><span lang="en-AU">80</span></span><span lang="zh-TW">个病区原定于当月稍后实施新标准，但政府推迟了计划，且未公布新的启动日期。</span></p>
<p><span lang="en-AU">ANMFWA</span>批评政府未事先与该组织协商，并要求提高人员配置、资金及资源安排的透明度。该分会警告，延误可能使护士和助产士继续面对工作压力及职业倦怠问题。</p>
<p>西澳政府计划于<span lang="en-AU">2027</span>年将新制度进一步推广至产科及精神卫生服务领域。</p>
