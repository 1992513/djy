<tr><td VALIGN=TOP width="626"><h2 align=center>昆州百强公立中学揭晓 状元学校再登榜首</h2>
<img width="600" src="https://i.epochtimes.com/assets/uploads/2013/08/1012300138391732-600x400.jpg" />
<h6>2026年昆州百强公立中学榜揭晓。（简彤／大纪元）</h6>
<hr>
<p>【大纪元2026年11月24日讯】大纪元记者肖婕澳洲悉尼编译报导）2026年昆州百强公立中学榜揭晓。昆州科学、数学与技术学院（QASMT）再创佳绩，连续两年夺魁，今年再次荣登昆州公立中学百强榜首。</p>
<p>该校在全澳公立中学百强榜中也稳居第四，排名与去年一样。</p>
<p>紧随其后跻身昆州前五名的学校依次是：布里斯班州立中学（Brisbane State High School）、曼斯菲尔德州立中学（Mansfield State High School,）、因杜鲁皮利州立中学（Indooroopilly State High School）和凯尔文格罗夫州立学院（Kelvin Grove State College）。</p>
<p>不过，最令人瞩目的当属玛丽谷州立学院（Mary Valley State College），该校排名与去年相比一举飙升了119位。</p>
<p>与此同时，奎纳洛学前至十年级州立学校（Quinalow Prep-10 State School）则证明，学校规模大小并不是决定排行的障碍。该校仅有94名学生，是榜单上规模最小的学校，却依然取得了第31名的出色成绩。</p>
<p>跻身昆州公立中学百强榜的学校各地都有，其中，贝诺瓦州立中学（Benowa State High School）排名第14，成为黄金海岸排名最高的学校；凯恩斯州立中学（Cairns State High School）则较去年跃升14位，升至全州第15名。</p>
<p>卡瓦纳沃特斯州立学院（Kawana Waters State College）以第22名成为阳光海岸排名最高的学校；而诺福克岛中央学校（Norfolk Island Central School）也表现出色，跻身第18名。</p>
<p>昆州科学、数学与技术学院是一所男女混合的精英中学，2025年在校学生人数为1358人。</p>
<p>该校校长凯鲁兹（Kathryn Kayrooz）表示，她对学校获评全州最佳学校感到“非常自豪”。</p>
<p>“我们拥有非常优秀的教师，他们竭尽所能，将自己所能给予的一切都倾注给了这些学生，”她说。</p>
<p>“我们非常重视对教学方法的期望，以及课堂应当呈现怎样的面貌、应当如何运作。”</p>
<p>凯鲁兹说，该校在学术上的成功源于对学生全面发展的重视。</p>
<p>“我们把学生称为能力出众的学习者，并有意使用这样的说法，因为他们确实能力出众，但仍需要得到悉心培养，”他说。</p>
<p>澳洲所有中学都接受了评估。评估指标包括学业表现、出勤率、师生比例、平均学费以及学生的社会教育优势等，评估结果用于编制全国百强中学榜单，以及各州独立的排名榜单。</p>
<p>悉尼音乐学院附中（Conservatorium High School）再次荣膺全澳最佳公立学校称号。这所男女混校的精英音乐专才学校仅招收153名学生，在出勤率、师生比例及NAPLAN（全澳英语与数学统考）方面均取得了优异成绩。</p>
<p>总体而言，在全澳百强公立中学中，新州占50所，维州25所，西澳13所，昆州8所，南澳3所，首都行政区一所。</p>
<p>跻身全澳百强公立中学的昆州学校包括：布里斯班州立中学（排名第41位）；卡文迪什路州立中学（Cavendish Road State High School，排名第74位），该校排名大幅上升45位；以及一举跃升92位、冲进第98名的肯莫尔州立中学（Kenmore State High School）。</p>
<p>编制澳洲公立中学百强排行榜是一项复杂的任务，远不止对成绩和声誉进行简单分析那么简单。</p>
<p>数据团队和教育记者采用了一套评估公式，从五个关键指标入手，对全澳1340多所符合条件的学校进行了评估。每项指标的权重各不相同，最终为每所学校计算出一个综合排名得分。</p>
<p>澳洲中学校长协会（ASPA）主席米森（Andy Mison）对澳洲公立中学的卓越表现表示赞扬。</p>
<p>“我们应当为国家的教育目标所作出的承诺，即确保每一位年轻人都能享有公平和优质的教育而感到自豪，”他说。</p>
